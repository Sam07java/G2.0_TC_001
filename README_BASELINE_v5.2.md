# GyanSetu Integrated DPE + ADSE v5

This build runs the full local pipeline with one command:

1. Reads raw `.xlsx`, `.xls`, or `.csv` files from `input/raw/`.
2. Classifies sheets by GyanSetu module.
3. Maps fields to the exact templates in `templates/`.
4. Cleans, repairs, normalizes, validates, and resolves duplicate identifiers.
5. Generates module CSV files and a combined workbook in `output/import-ready/`.
6. Enforces the DPE validation gates.
7. Copies validated module files to `runtime/imports/`.
8. Imports them into GyanSetu through Playwright when `CONFIRM_WRITE=true`.

## First-time setup

Install Node.js 18 or newer. Open Terminal/PowerShell in this folder and run:

```bash
npm install
npm run install:browsers
```

Copy `.env.example` to `.env` and set the actual GyanSetu credentials.

## Add raw institutional data

Remove the placeholder file from `input/raw/`, then place one or more raw Excel/CSV files there. A workbook may contain multiple module sheets.

## Validate without importing

```bash
npm run validate
```

This performs DPE preparation and stages the validated CSVs, but never opens the portal.

Review:

- `output/reports/latest-preparation.html`
- `output/import-ready/GyanSetu_Import_Ready_Data.xlsx`
- `runtime/imports/manifest.json`

## Validate and import

Set this in `.env`:

```env
CONFIRM_WRITE=true
DPE_REQUIRE_ZERO_REJECTIONS=true
DPE_REQUIRE_CLASSIFIED=true
```

Then run:

```bash
npm run adse
```

On macOS you may double-click `RUN_ADSE.command`. On Windows use `RUN_ADSE.bat`.

## Safety behavior

The browser importer will not run unless all enabled DPE validation gates pass and `CONFIRM_WRITE=true` is explicitly set.

Academic Session remains untouched. Subject Assignment remains verify-only. The remaining configured modules use the validated CSV files generated by the DPE.

## Outputs

- `output/import-ready/` — user-visible module CSVs and combined XLSX
- `output/rejected/` — rejected rows, if a strict validation rule still fails
- `output/reports/` — DPE and ADSE HTML/JSON reports
- `output/screenshots/` — browser evidence
- `output/logs/` — import logs
- `runtime/imports/` — validated files actually consumed by ADSE
